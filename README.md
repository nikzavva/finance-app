# Balance

Приложение для личного учёта финансов: счета, доходы, расходы и аналитика в одном месте.

## Возможности

- Ведение счетов в рублях, долларах, евро, фунтах и юанях.
- Создание, редактирование и удаление доходов и расходов с проверкой баланса.
- Офлайн-режим: операции сохраняются локально и синхронизируются после восстановления сети.
- Аналитика по периоду, типу операции, статьям и счёту; доступна сортировка по дате и сумме.
- Круговая диаграмма расходов с детализацией категорий.
- Настройки темы: светлая, тёмная или системная; переключение языка между русским и английским.
- Защита PIN-кодом и вход через Face ID / Touch ID.
- Хаптики, splash-анимация и скрытие содержимого в App Switcher.
- Адаптивный интерфейс для iPhone и iPad.

## Технологии

- Swift, SwiftUI и UIKit.
- MVVM.
- `URLSession` и offline-first синхронизация с сервером.
- SwiftData и Core Data с переключением хранилища и резервным копированием.
- UIKit-экран аналитики с ленивой загрузкой списка через `UITableView`.
- Локальный Swift Package `Utilities` с модулем `PieChart`; donut chart отрисовывается Core Graphics.
- Lottie для стартовой анимации.
- Core Haptics для тактильной отдачи и LocalAuthentication для биометрии.
- Локализация через `Localizable.xcstrings` для русского и английского языков.

## Структура

```text
finance-app/
├── App/          # Точка входа и жизненный цикл приложения
├── Models/       # Доменные модели
├── Services/     # Сетевой слой, синхронизация и проверка целостности данных
├── Storage/      # SwiftData, Core Data и резервные копии
├── ViewModels/   # Логика представления (MVVM)
├── Views/        # SwiftUI-экраны и UIKit-аналитика
├── Settings/     # Тема, язык, валюта и хаптики
├── Security/     # PIN-код, биометрия и защита App Switcher
└── Resources/    # Анимации и остальные ресурсы

Utilities/
└── Sources/PieChart/  # Локальная статическая библиотека диаграммы
```

## Запуск

1. Клонируйте репозиторий.
2. Откройте [finance-app.xcodeproj](finance-app.xcodeproj) в Xcode.
3. Выберите iPhone или iPad с iOS 18 и запустите схему `finance-app`.

> Для сборки нужен Xcode с поддержкой iOS 18 или новее. SwiftPM сам подтянет зависимость Lottie.
